=== Slide 8 ===
作用：侦听一个或多个响应式数据源，并在数据源变化时调用传入的回调函数。
用法：
导入watch函数
执行watch函数，传入要侦听的响应式数据源（ref对象）和回调函数；
watch
import { ref, watch } from 'vue'
const a = ref('')
watch(a, (newVal , oldVal) => { //侦听a的变化
console.log(`a的值为: newVal: ${newVal}, oldVal: ${oldVal}`);
})
=== Slide 9 ===
watch-侦听对象
侦听对象的单个属性：
import { ref, watch } from 'vue'
const user = ref({name:'', age:10})
watch( () => user.value.name , (newVal , oldVal) => {  //侦听user对象中name的变化
console.log(`a的值为: newVal: ${newVal}, oldVal: ${oldVal}`);
})
侦听对象的全部属性：
import { ref, watch } from 'vue'
const user = ref({name:'', age:10})
watch(user, (newVal , oldVal) => {  //侦听user对象中的全部属性的变化
console.log(`a的值为: newVal: ${newVal}, oldVal: ${oldVal}`);
}, {deep: true})
第三个可选参数，常见两个选项：
deep（boolean）：是否深度侦听，默认浅层侦听。
immediate（boolean）：是否在侦听创建时立即触发回调函数。
（深度侦听）
=== Slide 10 ===
watch侦听函数的作用?
侦听一个或多个响应式数据源，并在数据源变化时调用所给的回调函数
watch函数调用时传入的参数?
参数一：侦听的源，可以是一个ref对象，一个函数等。
参数二：侦听的源发生变化时，触发的回调函数
参数三：可选，是一个对象(deep、immediate)
能否侦听对象的一个属性或全部属性？
可以
侦听一个属性：第一个参数传递一个函数 () => user.value.name
侦听全部属性：第三个参数传递一个对象，指定deep深度侦听

接下来，要完成的是新增员工的功能，当点击页面上的 “新增员工” 按钮后，要弹出一个Dialog 对框框，在对话框中要承载一个用户信息的form表单。具体的要求如下:
1. 该对话框中的form表单在新增 和 修改员工时，使用的是同一个表单。 所以在新增员工时，表单标题显示为 “新增员工”， 修改员工时，表单的标题显示为 “修改员工” 。
2. 表单分为两个部分展示，一个部分是员工的基本信息，另外一部分为员工的工作经历信息 。
3. 员工的基本信息，包括以下几项，每一行展示两个表单项：
a. 第一行中展示两个表单项，为用户名 和 姓名。 两个表单项均为输入框，用户名的输入框提示信息 “请输入员工用户名，2-20个字”； 姓名输入框提示信息 “请输入员工姓名，2-10个字”
b. 第二行中展示两个表单项，性别 和 手机号表单项。 性别 为下拉框，展示 男 、女，男提交的值为1，女提交的值为2； 手机号为输入框，提示信息为 “请输入员工姓名”
c. 第三行中展示两个表单项，职位 和 薪资两个表单项。 职位 为下拉框，展示 班主任（提交值为1）、讲师（提交值为2）、学工主管（提交值为3）、教研主管（提交值为4）、咨询师（提交值为5）； 薪资为 输入框，提示信息 “请输入员工薪资”
d. 第四行中展示两个表单项，所属部门 和 入职日期表单项。 所属部门为下拉框，先写死两个测试数据。 入职日期为日期选择组件，可以选择日期，展示和提交的值格式都类似于这样 2024-05-09
e. 第五行中展示一个表单项，头像，这一列有点特殊，为图片上传组件，上传完图片后，要展示出预览图。
4. 在两个部分之间，添加一个按钮，按钮名为 “添加工作经历”。
5. 员工的工作经历信息，包括以下几项，在一行中要展示这三个表单项：
a. 时间：包括开始时间和结束时间，是一个日期范围组件。
b. 公司: 是一个输入框, 提示信息 "请输入公司名称"。
c. 职位: 是一个输入框, 提示信息 "请输入职位"。
时间 , 公司, 职位 这三个表单项要在一行中显示。
5. 在表单的方，有两个按钮，一个是保存，一个是取消。
6. 先不考虑表单校验。
