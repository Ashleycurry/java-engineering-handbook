变量的注意事项
1
变量要先声明才能使用
2
变量是什么类型，就必须装什么类型的数据
3
变量只在自己所归属的 { } 范围内有效
4
同一个范围内，变量的名称不能一样
5
变量定义的时候可以不赋初始值，但在使用时，变量里必须有值
6
一条语句可以定义多个变量，中间使用逗号分隔
